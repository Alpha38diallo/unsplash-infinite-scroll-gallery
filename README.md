# Unsplash Infinite Scroll Gallery

A responsive image gallery built with HTML, CSS, and JavaScript using the Unsplash API.

## Features

- Infinite scrolling
- Image search
- Unsplash API integration
- Responsive layout
- Loading indicator
- Modern JavaScript (ES6+)
- Intersection Observer API

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Unsplash API

## Preview

Users can search for images and continuously browse new content through an infinite scrolling experience.

## Project Structure

```text
.
├── images/
├── index.html
├── script.js
├── style.css
└── config.js (ignored from Git)
```

## Installation

Clone the repository:

```bash
git clone https://github.com/Alpha38diallo/unsplash-infinite-scroll-gallery.git
```

Enter the project:

```bash
cd unsplash-infinite-scroll-gallery
```

Create a `config.js` file:

```javascript
const UNSPLASH_ACCESS_KEY = "YOUR_ACCESS_KEY";
```

Open:

```text
index.html
```

in your browser.

## API Key

This project uses the Unsplash API.

Create a developer account and generate an Access Key from:

https://unsplash.com/developers
